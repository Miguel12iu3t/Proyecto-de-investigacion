# Proyecto-de-investigacion
Proyecto protección civil: integrado por los estados de Jalisco, Colima, Michoacán de Ocampo y Nayarit— concentra 268 municipios expuestos a múltiples fenómenos naturales

- El programa está realizado en una libreta de Jupyter, para tener un mejor acomodo de secciones y hacer que el usuario que desee ponerlo a prueba no se sature de información gracias a que el proyecto no es un .py normal, así que habrá más claridad en los datos en forma visual.
